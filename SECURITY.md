# Security policy

Security fixes are applied to the latest `main` branch. Older snapshots are not maintained as separate supported release lines.

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting or a private security advisory for the repository, and include the affected endpoint or module, impact, prerequisites, and the smallest safe reproduction you can provide. Do not include real credentials, tokens, personal data, or production dumps.

The implementation baseline, deployment checklist, dependency scan command, and disclosure-sensitive test areas are documented in [docs/SECURITY.md](docs/SECURITY.md).
